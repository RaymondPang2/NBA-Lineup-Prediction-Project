# Power BI semantic model reference

Generated by `scripts/phase9/build_powerbi_project.py` from `src/nba_lineups/bi/model.py` and `report.py`. Do not edit by hand. The guide is [docs/powerbi.md](powerbi.md).

## Tables

| Table | Rows come from | Description |
|---|---|---|
| `dim_season` | SQL view `bi.dim_season` | One row per season (2018-19 to 2025-26). Held-out seasons were never used to train or tune the model. |
| `dim_team` | SQL view `bi.dim_team` | One row per NBA team. |
| `dim_player` | SQL view `bi.dim_player` | Players who appear in at least one lineup. |
| `dim_window` | SQL view `bi.dim_window` | The two date windows of each season, split at the All-Star break. |
| `dim_lineup` | SQL view `bi.dim_lineup` | One row per five-man lineup (a season, a team and five players). Filtered by players through the bridge. |
| `bridge_lineup_player` | SQL view `bi.bridge_lineup_player` | Lineup ↔ player (five rows per lineup). Resolves the many-to-many relationship. |
| `fact_lineup_window` | SQL view `bi.fact_lineup_window` | Additive totals per lineup and window. Ratings are measures, never stored. |
| `fact_team_window` | SQL view `bi.fact_team_window` | Team games, wins and losses per season and window (from game logs). |
| `fact_prediction` | export script (frozen model) | Frozen-model predictions for every lineup that played after the break, scored from PRE-break data only; the observed post-break rating is the outcome, never an input. |
| `model_parameters` | export script (frozen model) | Constants of the frozen model (one row). |
| `_Measures` | none (holds measures) | Home of every measure (no data). |

### 2 Ratings

**ORtg** · format `0.0`  
Offensive rating: 100 × Σ points ÷ Σ own possessions.

```dax
DIVIDE ( SUM ( fact_lineup_window[pts] ), SUM ( fact_lineup_window[poss] ) ) * 100
```

**DRtg** · format `0.0`  
Defensive rating: 100 × Σ opponent points ÷ Σ opponent possessions (lower is better).

```dax
DIVIDE ( SUM ( fact_lineup_window[opp_pts_rated] ), SUM ( fact_lineup_window[opp_poss] ) ) * 100
```

**Net Rating** · format `+0.0;-0.0;0.0`  
ORtg − DRtg. Blank unless both are defined.

```dax
VAR o = [ORtg]
VAR d = [DRtg]
RETURN IF ( NOT ISBLANK ( o ) && NOT ISBLANK ( d ), o - d )
```

**Lineup Net Avg (possession-weighted)** · format `+0.0;-0.0;0.0`  
Possession-weighted average of the lineups' own net ratings. Close to, but not identical with, the pooled Net Rating.

```dax
VAR t = FILTER ( ADDCOLUMNS ( VALUES ( dim_lineup[lineup_id] ), "@n", [Net Rating], "@w", [Possessions] ), NOT ISBLANK ( [@n] ) )
RETURN DIVIDE ( SUMX ( t, [@w] * [@n] ), SUMX ( t, [@w] ) )
```

**Lineup Net Avg (unweighted, misleading)** · format `+0.0;-0.0;0.0`  
Simple mean of lineup net ratings. Shown only to demonstrate why ratings must not be averaged: tiny samples dominate.

```dax
AVERAGEX ( FILTER ( ADDCOLUMNS ( VALUES ( dim_lineup[lineup_id] ), "@n", [Net Rating] ), NOT ISBLANK ( [@n] ) ), [@n] )
```

### 4 Reliability

**K (noise constant)** · format `#,0`  
Sampling-noise constant of the frozen model (≈ 14,639).

```dax
MAX ( model_parameters[k_noise] )
```

**Net Rating SE** · format `0.0`  
Sampling standard error of the net rating: √(K·(1/poss + 1/opp_poss)).

```dax
VAR p = [Possessions]
VAR q = [Opp Possessions]
RETURN IF ( p > 0 && q > 0, SQRT ( [K (noise constant)] * ( 1 / p + 1 / q ) ) )
```

**Net Rating 95% Low** · format `+0.0;-0.0;0.0`  
Lower end of the 95% sampling interval.

```dax
VAR n = [Net Rating]
VAR se = [Net Rating SE]
RETURN IF ( NOT ISBLANK ( n ) && NOT ISBLANK ( se ), n - 1.959964 * se )
```

**Net Rating 95% High** · format `+0.0;-0.0;0.0`  
Upper end of the 95% sampling interval.

```dax
VAR n = [Net Rating]
VAR se = [Net Rating SE]
RETURN IF ( NOT ISBLANK ( n ) && NOT ISBLANK ( se ), n + 1.959964 * se )
```

**Net Change SE** · format `0.0`  
Standard error of the pre→post change (independent windows).

```dax
VAR a = CALCULATE ( [Net Rating SE], dim_window[window_type] = "pre_asb" )
VAR b = CALCULATE ( [Net Rating SE], dim_window[window_type] = "post_asb" )
RETURN IF ( NOT ISBLANK ( a ) && NOT ISBLANK ( b ), SQRT ( a ^ 2 + b ^ 2 ) )
```

**Change Exceeds Noise** · format `0`  
1 if |change| > 1.96 SE (larger than sampling noise alone).

```dax
VAR c = [Net Change]
VAR se = [Net Change SE]
RETURN IF ( NOT ISBLANK ( c ) && NOT ISBLANK ( se ), IF ( ABS ( c ) > 1.959964 * se, 1, 0 ) )
```

**Reliability** · format `0%`  
Share of the net rating's variance that is signal (vs the team prior): τ² / (τ² + K·h). With the pre-break window in context it equals the model's per-lineup reliability.

```dax
VAR p = [Possessions]
VAR q = [Opp Possessions]
VAR tau2 = MAX ( model_parameters[lineup_tau2] )
RETURN IF ( p > 0 && q > 0, DIVIDE ( tau2, tau2 + [K (noise constant)] * ( 1 / p + 1 / q ) ) )
```

**Lineups ≥ 100 Poss** · format `#,0`  
Lineups with at least 100 possessions on each end in context.

```dax
COUNTROWS ( FILTER ( VALUES ( dim_lineup[lineup_id] ), [Possessions] >= 100 && [Opp Possessions] >= 100 ) )
```

**Share of Possessions in Lineups ≥ 100** · format `0%`  
How much of the playing time comes from lineups with a usable sample.

```dax
DIVIDE ( SUMX ( FILTER ( VALUES ( dim_lineup[lineup_id] ), [Possessions] >= 100 && [Opp Possessions] >= 100 ), [Possessions] ), [Possessions] )
```

**Lineup Net SD (possession-weighted)** · format `0.0`  
Spread of lineup net ratings. Compare with Noise SD: most of the spread at small samples is noise.

```dax
VAR t = FILTER ( ADDCOLUMNS ( VALUES ( dim_lineup[lineup_id] ), "@n", [Net Rating], "@w", [Possessions] ), NOT ISBLANK ( [@n] ) )
VAR m = DIVIDE ( SUMX ( t, [@w] * [@n] ), SUMX ( t, [@w] ) )
RETURN SQRT ( DIVIDE ( SUMX ( t, [@w] * ( [@n] - m ) ^ 2 ), SUMX ( t, [@w] ) ) )
```

**Noise SD (possession-weighted)** · format `0.0`  
Spread that pure sampling noise would produce for the same lineups.

```dax
VAR t = FILTER ( ADDCOLUMNS ( VALUES ( dim_lineup[lineup_id] ), "@se", [Net Rating SE], "@w", [Possessions] ), NOT ISBLANK ( [@se] ) )
RETURN SQRT ( DIVIDE ( SUMX ( t, [@w] * [@se] ^ 2 ), SUMX ( t, [@w] ) ) )
```

**Skill vs Team Prior** · format `0.0%`  
1 − MSE(model) ÷ MSE(team prior): share of the baseline's squared error removed.

```dax
VAR t = FILTER ( fact_prediction, fact_prediction[in_evaluation_sample] = 1 && NOT ISBLANK ( fact_prediction[observed_post_net] ) )
VAR w = SUMX ( t, fact_prediction[post_poss] )
VAR mseModel = DIVIDE ( SUMX ( t, fact_prediction[post_poss] * ( fact_prediction[observed_post_net] - fact_prediction[predicted_net] ) ^ 2 ), w )
VAR msePrior = DIVIDE ( SUMX ( t, fact_prediction[post_poss] * ( fact_prediction[observed_post_net] - fact_prediction[team_prior_net] ) ^ 2 ), w )
RETURN IF ( msePrior > 0, 1 - DIVIDE ( mseModel, msePrior ) )
```

**Observed Variance** · format `0.0`  
Possession-weighted variance of the observed post-break net rating (R² denominator).

```dax
VAR t = FILTER ( fact_prediction, fact_prediction[in_evaluation_sample] = 1 && NOT ISBLANK ( fact_prediction[observed_post_net] ) )
VAR w = SUMX ( t, fact_prediction[post_poss] )
VAR m = DIVIDE ( SUMX ( t, fact_prediction[post_poss] * fact_prediction[observed_post_net] ), w )
RETURN DIVIDE ( SUMX ( t, fact_prediction[post_poss] * ( fact_prediction[observed_post_net] - m ) ^ 2 ), w )
```

**Model R²** · format `0.000`  
1 − MSE ÷ Var(y), possession-weighted, around the evaluated rows' own mean.

```dax
VAR v = [Observed Variance]
RETURN IF ( v > 0, 1 - DIVIDE ( [Model RMSE] ^ 2, v ) )
```

RETURN DIVIDE ( SUMX ( t, fact_prediction[post_poss] * fact_prediction[predicted_net] ), SUMX ( t, fact_prediction[post_poss] ) )
```

Possession-weighted mean team-prior baseline (evaluation sample).

```

**Mean Observed** · format `+0.0;-0.0;0.0`  
Possession-weighted mean observed post-break net rating (evaluation sample).

```dax
VAR t = FILTER ( fact_prediction, fact_prediction[in_evaluation_sample] = 1 && NOT ISBLANK ( fact_prediction[observed_post_net] ) )

```

**Mean Prediction Error** · format `+0.0;-0.0;0.0`  
Observed minus predicted (possession-weighted). Near 0 = unbiased in this slice.

```dax
VAR o = [Mean Observed]
VAR p = [Mean Predicted]
RETURN IF ( NOT ISBLANK ( o ) && NOT ISBLANK ( p ), o - p )
```

### 7 Selection

**Population Lineups** · format `#,0`  
Lineups with ≥ 25 pre-break possessions on each end.

```dax
CALCULATE ( DISTINCTCOUNT ( fact_lineup_window[lineup_id] ), dim_lineup[in_continuation_population] = 1, dim_window[window_type] = "pre_asb" )
```

**Continuing Lineups** · format `#,0`  
Population lineups that played ≥ 25 possessions after the break.

```dax
CALCULATE ( DISTINCTCOUNT ( fact_lineup_window[lineup_id] ), dim_lineup[in_continuation_population] = 1, dim_lineup[continues_post_break] = 1, dim_window[window_type] = "pre_asb" )
```

**Appearing Lineups** · format `#,0`  
Population lineups with any post-break possession.

```dax
CALCULATE ( DISTINCTCOUNT ( fact_lineup_window[lineup_id] ), dim_lineup[in_continuation_population] = 1, dim_lineup[appears_post_break] = 1, dim_window[window_type] = "pre_asb" )
```

**Continuation Rate** · format `0.0%`  
Share of pre-break lineups that keep playing (≥ 25 possessions) after the break.

```dax
DIVIDE ( [Continuing Lineups], [Population Lineups] )
```

**Appearance Rate** · format `0.0%`  
Share of pre-break lineups seen at all after the break.

```dax
DIVIDE ( [Appearing Lineups], [Population Lineups] )
```

```dax
CALCULATE ( [Net Rating Pre], dim_lineup[in_continuation_population] = 1, dim_lineup[continues_post_break] = 1 )
```

Pooled pre-break net rating of lineups that do not continue.

```dax

```

### 8 Filters

**All Selected Players In Lineup** · format `0`  
Visual-level filter (= 1) for AND semantics: keep lineups that contain EVERY selected player. Without it a multi-player slicer means 'contains ANY selected player'.

```dax
VAR nSel = COUNTROWS ( ALLSELECTED ( dim_player[player_id] ) )
VAR nAll = COUNTROWS ( ALL ( dim_player[player_id] ) )
VAR nIn = DISTINCTCOUNT ( bridge_lineup_player[player_id] )
RETURN IF ( nSel = nAll || nIn = nSel, 1, 0 )
```
